# 🎯 Number Guessing Game (Python)

A simple command-line Number Guessing Game built with Python. The computer randomly selects a number, and the player tries to guess it within a limited number of attempts based on the selected difficulty level.

## How to Play

1. Run the program.
2. Choose a difficulty level.
3. The computer randomly selects a number.
4. Enter your guess.
5. Try to guess the correct number before running out of attempts.

If your guess matches the computer's number, **you win!**

## Difficulty Levels

| Difficulty | Number of Attempts |
|---|---:|
| Easy (1) | 7 |
| Medium (2) | 5 |
| Hard (3) | 3 |

The higher the difficulty, the fewer attempts you get!

## Features

- Random number generation
- Three difficulty levels
- Limited guessing attempts
- Command-line interface (CLI)
- Simple and interactive gameplay

## Technologies Used

- **Language:** Python
- **Modules:** `random`, `time`

## Getting Started

### Prerequisites

Make sure Python 3 is installed on your computer.

### Installation & Execution

1. Clone the repository:

   ```bash
   git clone https://github.com/Tazbin-Hossen/Number-Guessing-Game.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Number-Guessing-Game
   ```

3. Run the game:

   ```bash
   python main.py
   ```
